# وارد کردن داده‌ها (Importing Data)

## برنامه‌های تمرینی (Plans)

برنامه‌ها و روال‌های تمرینی (Plans/Routines) را می‌توان از یک فایل متنی JSON وارد کرد.  
این برنامه از برون‌بری (Export) پشتیبانی می‌کند و فایل خروجی همواره شامل *تمام* برنامه‌های فعلی شماست.  

اگر نمی‌خواهید تمام برنامه‌هایی که در حال حاضر ایجاد کرده‌اید را به اشتراک بگذارید، می‌توانید یکی از دو راه زیر را انجام دهید:
- فایل JSON خروجی گرفته شده را با یک ویرایشگر متن ویرایش کنید  
  یا (اگر مایل به ویرایش مستقیم فایل‌های JSON نیستید):
- نسخه پیش‌نمایش [Demo](https://opengym.duarte-santos.ch/demo/#/home) را باز کنید
    - برنامه‌های خود را وارد (Import) کنید
    - تغییرات مدنظرتان را اعمال کنید 
    - یک فایل JSON جدید جهت اشتراک‌گذاری برون‌بری (Export) کنید

اگر از اپلیکیشن مستقل روی گوشی همراه خود استفاده می‌کنید، می‌توانید از نسخه دمو برای ایجاد برنامه‌ها روی کامپیوتر استفاده کرده و سپس آن‌ها را وارد گوشی کنید.  
نسخه دمو تمام داده‌ها را در مرورگر شما ذخیره می‌کند و به هیچ وجه عمومی یا به اشتراک گذاشته نمی‌شود.

نوشتن دستی فایل JSON ممکن است کار نسبتاً پیچیده‌ای باشد، زیرا شناسه‌های (ID) تمرینات باید با شناسه‌های موجود در پایگاه داده مطابقت داشته باشند.  

## تاریخچه تمرینات (History)

برای وارد کردن تاریخچه تمرینات خود از سایر اپلیکیشن‌ها، به یک فایل خروجی با فرمت `CSV` نیاز خواهید داشت.  
برنامه تلاش می‌کند نام تمرینات را مطابقت دهد تا آن‌ها را به تمرینات موجود در پایگاه داده متصل کند.

> نکته: تاریخچه، ثبت و لاگ تمرینات گذشته است.  
> از آنجایی که برنامه‌ها ممکن است تغییر کنند اما تاریخچه تغییر نمی‌کند، تاریخچه کاملاً از روال‌ها و برنامه‌های تمرینی جداست.  
> 
> تطبیق تمرینات بر اساس نام آن‌ها انجام می‌شود، بنابراین تمرینات سفارشی (Custom) ممکن است نام‌گذاری متفاوتی داشته باشند، همان‌طور که ممکن است در سایر برنامه‌ها نیز متفاوت باشند.

این برنامه‌ها تست شده‌اند و بدون نیاز به دستکاری نام ستون‌ها کار می‌کنند:

| برنامه | نحوه برون‌بری (خروجی گرفتن) | 
|---|---|
| **FitNotes (Android)** | Settings → Backup/Export → **Spreadsheet Export** | 
| **FitNotes 2 (iOS)** | خروجی تمرینات به‌صورت CSV؛ همچنین پشتیبان‌گیری دستی یا خودکار iCloud |
| **Strong** | Settings → Export Data | 
| **Gravl** | Profile → Export Data | 
| **Hevy** | Profile → Settings → Export & Import Data (Workouts یا Measurements)، **یا** Settings → Import from Hevy با کلید API نسخه Pro |

### رابط Hevy API (مستقیم)

اگر اشتراک **Hevy Pro** دارید، می‌توانید از ساخت فایل CSV صرف‌نظر کرده و داده‌ها را مستقیماً از Hevy وارد کنید:

1. بخش [Hevy → Settings → Developer](https://hevy.com/settings?developer) را باز کرده و یک کلید API ایجاد کنید
2. در openGym: مسیر **Settings → Import from Hevy** را باز کنید
3. کلید را جای‌گذاری (Paste) کنید (فقط برای همان نوبت وارد کردن استفاده می‌شود و ذخیره نخواهد شد)
4. انتخاب کنید که آیا مایل به وارد کردن **تمرینات (workouts)**، **برنامه‌ها (routines)**، **ثبت وزن (weigh-ins)** یا هر ترکیبی از آن‌ها هستید، سپس تأیید کنید

هم فرایند ورود از طریق API و هم فایل **Hevy CSV** تشخیص داده شده، تمرینات را از طریق یک جدول تطبیق تولید شده یکسان (`frontend/src/lib/hevy-id-map.js`) شناسایی می‌کنند: شناسه الگو برای API و عنوان انگلیسی برای CSV.  
جهت بازتولید (برای توسعه‌دهندگان): متغیر `HEVY_API_KEY` را در محیط یا فایل `.env` تنظیم کرده و سپس دستور `node scripts/build-hevy-id-map.mjs` را اجرا کنید. حرکاتی که تطبیق پیدا نکنند به تمرینات سفارشی خودتان تبدیل می‌شوند. روزهای تمرینی که قبلاً در اینجا داده دارند دست‌نخورده باقی می‌مانند؛ برنامه‌ها همیشه به عنوان برنامه‌های **جدید** اضافه می‌شوند (هیچ موردی از اطلاعات فعلی شما بازنویسی نمی‌شود). عناوین بومی‌سازی شده CSV (غیرانگلیسی) کماکان از تطبیق نام استفاده می‌کنند.

همچنین می‌توانید فایل `CSV` اختصاصی خود را بسازید:

### نمونه حداقلی (Minimal Example)

```csv
workout name,exercise,date,weight kg,reps
Leg Day,Squat,2026-08-21,120,5
Leg Day,Squat,2026-08-21,125,4
Leg Day,Leg Press,2026-08-21,200,1
```

این نام فیلدها پشتیبانی می‌شوند:

| فیلد استاندارد | سرستون‌های CSV پشتیبانی‌شده (اولین تطبیق اعمال می‌شود) |
|---|---|
| `exercise` | `exercise`, `exercise name`, `exercise title` |
| `date` | `date`, `workout date` |
| `startTime` | `start time`, `start date` |
| `endTime` | `end time` |
| `workoutName` | `workout name`, `title`, `workout` |
| `category` | `category`, `body part`, `muscle group` |
| `weightKg` | `weight kg` |
| `weightLb` | `weight lbs`, `weight lb` |
| `weight` | `weight` |
| `weightUnit` | `weight unit`, `unit` |
| `reps` | `reps`, `repetitions` |
| `rpe` | `rpe`, `rpe rating` |
| `rir` | `rir`, `reps in reserve` |
| `distanceKm` | `distance km` |
| `distance` | `distance` |
| `distanceUnit` | `distance unit` |
| `seconds` | `seconds`, `duration seconds`, `set duration sec` |
| `time` | `time`, `duration` |
| `setType` | `set type` |
| `note` | `comment`, `comments`, `notes`, `note`, `workout notes` |
